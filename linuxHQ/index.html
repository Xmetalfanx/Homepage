My Goal:

My Goal is to help users see the differences between the different Linux Desktop Distros, and also the relationship between them and to hopefully help find the combination that works for them.

I also want to promote open source software and Linux (as well as potentially adding BSD).

What this LinuxHQ section includes

  • Linux Desktop options including screenshots, system requirments, and info on what version is in what Linux Distribution
  • Linux Distrobution information including currently supported release and desktop options and screenshots
